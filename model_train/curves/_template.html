Epoch Watch

Per-epoch training and validation curves for every model run in the GEDI biomass project, parsed straight from the SLURM logs in model_train/out_and_err/. Re-running the parser while a job is training picks up whatever epochs have finished, so this doubles as a live progress check.

Loss values are not comparable between runs. Early versions trained on raw Mg/ha, then log1p, and the newest on sqrt, with the Huber delta rescaled 1.0 to 5.0 at that switch. Only the shape of a curve and the train-to-validation gap inside one run carry meaning across versions. Use Normalized scale to compare shapes directly.
